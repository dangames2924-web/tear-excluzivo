COMPILAR O MOD PELO GITHUB (sem instalar nada)

1) Crie uma conta gratuita em https://github.com e depois um repositorio novo
   (botao "New repository"; pode ser Private; marque "Add a README file" para a pagina nao ficar vazia).

2) Extraia este ZIP no seu computador. No repositorio, clique em
   "Add file" > "Upload files" e ARRASTE para la, de dentro da pasta extraida:
     - a pasta  src
     - os arquivos  build.gradle, settings.gradle, gradle.properties
   (nao precisa enviar o LEIA-ME nem os outros). Clique em "Commit changes".

3) Ainda no repositorio: "Add file" > "Create new file". No campo do nome digite exatamente:
     .github/workflows/build.yml
   (ao digitar a barra "/", o GitHub cria as pastas). Cole dentro o conteudo do arquivo
   COLE-NO-GITHUB-build.yml.txt e clique em "Commit changes".

4) Abra a aba "Actions" do repositorio. A compilacao comeca sozinha (1 a 3 minutos).
   Quando aparecer um check verde, clique nela e baixe o arquivo em "Artifacts" (tear-exclusivo-mod).
   Dentro do ZIP baixado esta o .jar do mod.

5) Se aparecer um X vermelho: clique na execucao, abra o passo que falhou, copie o erro e
   mande para o Claude.

6) No servidor: coloque o .jar na pasta mods (junto com Fabric API e Cobblemon), inicie uma vez,
   e substitua config/tear_exclusivo.json pelo arquivo tear_exclusivo.json desta pasta,
   trocando COLOQUE-O-UUID-DO-ALFAIATE-AQUI pelo UUID real. Use /alfaiate reload.
